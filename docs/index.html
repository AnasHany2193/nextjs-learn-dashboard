Beyond the Next.js course

The official Next.js Learn course builds the Acme dashboard and stops at fifteen chapters. These are the chapters after that — written while extending the same app, each one documenting the bugs found along the way rather than a clean happy path.

Built on Next 16.3.3, React 19.2.8, Tailwind 3.4, Postgres on Neon, and next-auth v5 beta.

Repository Live app Next 16.3.3 React 19.2.8
  • Chapter 16 Built

    Finish the project

    The course ends with a stub page, a fully-written component nobody imports, and a login screen whose password is hidden in a code comment. Closing all three, then giving customers the create, edit and delete that invoices already had — including the missing foreign key that lets one delete quietly desync the dashboard.
  • Chapter 17 Planned

    Bilingual routing and Arabic RTL

    Moving fifteen route files under a [locale] segment, composing next-intl's locale detection with next-auth in a single proxy.ts, and replacing eighty physical-direction Tailwind utilities with logical ones so the layout mirrors properly for Arabic.

Written by Anas Hany. The dashboard itself sits behind a login, so these chapters are about the engineering, not a public product.
